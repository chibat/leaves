# @chibat/leaves

Search and read posts from [Leaves](https://leaves.chiba.dev/) in a terminal.

## Requirements

- Node.js 22.12 or later

## Usage

```sh
npx @chibat/leaves
```

To use a Leaves development server running at `http://localhost:8000`:

```sh
npx @chibat/leaves dev
```

Enter a search term, then select a post. Use the arrow keys or `j`/`k` to move
through the menu. Select `:Back` to search again or `:Exit` to quit. In a
non-interactive terminal, menu items can be selected by number.
